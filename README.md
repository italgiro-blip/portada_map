# 🇺🇾 Visor Geográfico - Área de Estadística y Análisis

Este proyecto es un **Visualizador Geográfico Interactivo** diseñado para el análisis territorial y estadístico de la República Oriental del Uruguay. La aplicación cuenta con una pantalla de inicio minimalista y una interfaz de mapa avanzada que permite la manipulación de capas y datos estadísticos.

## ✨ Características Principales

*   **Interfaz de Usuario Limpia:** Pantalla de inicio con diseño minimalista y botón de acceso central.
*   **Mapa Base Configurable:** Soporte para múltiples mapas base, incluyendo *OpenStreetMap* por defecto.
*   **Importación de Capas:** Funcionalidad para cargar datos geográficos externos (GeoJSON, KML, etc.).
*   **Análisis Estadístico:** Selección de métodos estadísticos avanzados (ej. *Optimizar Grupos - Jenks*) para la clasificación de datos.
*   **Esquemas Cromáticos:** Personalización visual mediante escalas de colores (ej. *Escala de Azules*) para representar variables.
*   **Filtros Administrativos:** Selección de entidades administrativas (Departamentos, Municipios) para el análisis específico.
*   **Visualización de Datos:** Panel lateral que muestra la unidad y el valor de los datos seleccionados en el mapa.

## 🛠️ Tecnologías Utilizadas (Sugeridas/Comunes)

*   **Frontend:** HTML5, CSS3, JavaScript (o framework como React/Vue).
*   **Librería de Mapas:** [Leaflet](https://leafletjs.com/) o [OpenLayers](https://openlayers.org/).
*   **Estilos:** CSS Grid/Flexbox para el layout del panel lateral.
*   **Datos:** GeoJSON / Shapefiles (procesados).
